Modellin of spherizone process
# Multi-Site Flory Reactor Model for Spherizone ICP Prediction

This package contains the MATLAB scripts and CSV result files used to reproduce the manuscript and Supporting Information figures for:

**A Multi-Site Flory Reactor Model for Spherizone Impact Copolymer Production: From MZCR Calibration to Gas-Phase ICP Prediction**

The model predicts homopolymer polypropylene (HPP), random copolymer polypropylene (RCP), mixed-PP, and impact copolymer polypropylene (ICP) properties using a multi-site Flory description of Ziegler–Natta catalyst behavior, non-ideal monomer sorption, MZCR reactor balances, and a downstream gas-phase reactor calculation.

---

## 1. Package contents

The reproducibility package is organized around two folders or zip files:

```text
Scripts.zip
Results.zip
```

`Scripts.zip` contains the MATLAB source files.  
`Results.zip` contains the CSV files used to plot the main-text and Supporting Information figures.

The static manuscript and Supporting Information outputs are generated by:

```text
run_all_manuscript_results_PFR_H2.m
```

The dynamic grade-transition result in Figure 7 is generated separately by:

```text
run_grade_transition_dynamic.m
```

## 4. Main workflow

### 4.1 Static manuscript and SI figures

Run:

```matlab
run_all_manuscript_results_PFR_H2
```

This master script performs the full static workflow:

1. EX1 homopolymer calibration.
2. EX2 random copolymer calibration.
3. Industrial iPP calculation.
4. ICP prediction without ICP-specific fitting.
5. Mixed-PP and sensitivity calculations.
6. Particle-size-distribution calculation.
7. Stockmayer CCD calculation for EX2.
8. Temperature and catalyst-deactivation sensitivity analyses.
9. Grade-design map calculation.
10. Export of CSV files for the main-text and Supporting Information figures.

This script generates the static outputs for:

```text
Figures 3–6
Figures S1–S16
```

### 4.2 Dynamic grade-transition figure

Run:

```matlab
run_grade_transition_dynamic
```

This stand-alone script generates:

```text
Figure 7
Fig7_grade_transition.csv
```

The dynamic model uses a simplified CSTR-type representation of the downstream gas-phase reactor and simulates a step change in gas-phase ethylene feed.

## 5. Script descriptions

| File | Purpose |
|---|---|
| `init_flory_data.m` | Stores the 16 experimental multi-site Flory data points from Alshaiban (2011). |
| `interpFlory.m` | Constructs scattered interpolants for each site's weight fraction and number-average molecular weight as functions of temperature, hydrogen pressure, and donor/Ti ratio. |
| `local_flory.m` | Wrapper function returning site weights and site number-average molecular weights: `(w, Mn) = f(T, P_H2, DoTi)`. |
| `activity_model.m` | Calculates specific polymerization rate as a function of temperature and hydrogen pressure. |
| `get_monomer_concentrations.m` | Calculates amorphous-phase concentrations of propylene, ethylene, and hydrogen. Propylene uses the ternary correlation; hydrogen and ethylene use Henry's law. |
| `mzcr_pfr_model.m` | Homopolymer MZCR PFR model for EX1/iPP. |
| `mzcr_pfr_copolymer.m` | Random copolymer MZCR PFR model for EX2, using Mayo–Lewis copolymerization. |
| `mzcr_pfr_model_PSD_simple.m` | Deterministic particle-growth model used for PSD prediction. |
| `stockmayer_ccd.m` | Calculates the Stockmayer bivariate molecular-weight–composition distribution for EX2. |
| `run_all_manuscript_results_PFR_H2.m` | Master script for static manuscript/SI results. |
| `run_grade_transition_dynamic.m` | Stand-alone dynamic CSTR grade-transition simulation for Figure 7. |

## 6. Calibration and prediction strategy

The workflow separates calibration and prediction.

### Calibration cases

The model is calibrated using only:

```text
EX1 homopolymer polypropylene
EX2 random copolymer polypropylene
```

The fitted/calibrated parameters are:

```text
MZCR hydrogen partial pressure: 2.54 psi
Ethylene/propylene reactivity ratio r1: 4.00
Ethylene/propylene reactivity ratio r2: 0.79
```

The first-order catalyst deactivation constant is taken independently from the literature:

```text
kd = 0.5 h^-1
```

### Prediction case

The ICP case is treated as a forward model prediction:

```text
No ICP-specific composition, phase-fraction, or molecular-weight data are used to tune the model.
```

The ICP prediction uses the EX1/EX2-calibrated parameters, the independently specified catalyst deactivation constant, and the downstream gas-phase reactor model.

## 8. Important notation

The following notation is used consistently in the manuscript, SI, scripts, and result interpretation:

| Symbol or term | Meaning |
|---|---|
| `MW` in code or CSV headers | Molecular-weight coordinate array, equivalent to \(M\). |
| \(M\) | Molecular-weight coordinate in the distribution. |
| \(M_w\) | Weight-average molecular weight. |
| \(M_n\) | Number-average molecular weight. |
| MWD | Molecular-weight distribution. |
| \(w(\log M)\) | Normalized differential weight distribution, \(dW/d\log M\). |
| \(W\) | Normalized polymer weight basis. |
| \(w(\log M,F_1)\) | Joint CCD density, \(dW/d\log M\,dF_1\). |
| \(F_1\) | Propylene mole-fraction coordinate. |
| \(\bar{F}_1\) | Mean propylene mole fraction from the Mayo–Lewis equation. |

In figure labels and manuscript equations, use \(M\) for the molecular-weight coordinate. Use \(M_w\) only for the weight-average molecular weight.

## 9. Notes on selected calculations

### Figure S4: recirculation ratio

The residence time in Figure S4a is an assumed/scaled downer catalyst residence time:

```text
tau_D = tau_D,0 (R_rec / 23.5)
tau_D,0 = 1.0 h
```

Thus:

```text
R_rec = 15  -> tau_D = 0.6383 h
R_rec = 60  -> tau_D = 2.5532 h
```

This residence time is not independently solved from a detailed hydrodynamic model.

### Figure S13: single-site comparison

Figure S13 compares the calibrated multi-site Flory MWD for EX1 with a single-site most-probable Flory distribution having the same number-average molecular weight, M_n = 61,609 g mol^-1. The y-axis is:

```text
dW/dlogM
```

and the x-axis is:

```text
M
```

where \(M\) is the molecular-weight coordinate, not \(M_w\).

### Figure S14: Stockmayer CCD

Figure S14 uses the Stockmayer bivariate distribution:

```text
w(logM, F1) = dW / (dlogM dF1)
```

where \(F_1\) is the propylene mole-fraction coordinate and \(\bar{F}_1\) defines the center of the composition distribution.

## 11. Reproducibility checklist

Before comparing outputs with the manuscript and SI:

1. Confirm that all `.m` files are in the MATLAB path.
2. Run `run_all_manuscript_results_PFR_H2.m`.
3. Confirm that the CSV files for Figures 3–6 and S1–S16 are generated.
4. Run `run_grade_transition_dynamic.m`.
5. Confirm that `Fig7_grade_transition.csv` is generated.
6. Plot the figures using the CSV files in `Results.zip`.
7. Check that Figure S14 uses \(M\), not \(M_w\), as the molecular-weight coordinate.
8. Check that Figure S13 uses \(dW/d\log M\) on the y-axis and \(M\) on the x-axis.
